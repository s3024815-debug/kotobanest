KotobaNest Curriculum + Admin Patch

1. Copy all folders/files from this ZIP into:
   C:\Users\akash\kotobanest_final
2. Choose Replace the files in the destination.
3. Run:
   cd C:\Users\akash\kotobanest_final
   php artisan migrate
   php artisan db:seed --class=CourseCurriculumSeeder
   php artisan optimize:clear
   npm run build
   php artisan serve
4. Open:
   http://127.0.0.1:8000/courses
   http://127.0.0.1:8000/admin/curriculum
