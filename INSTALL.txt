KotobaNest Hierarchical Admin Curriculum Patch

1. Copy the app and resources folders into:
   C:\Users\akash\kotobanest_final
   Choose Replace files.

2. Open routes\web.php and add the four routes from ROUTES_TO_ADD.txt immediately after:
   Route::get('/admin/curriculum', ...)

3. Delete the old file if it remains:
   resources\views\admin\curriculum.blade.php
   (The new design uses the resources\views\admin\curriculum\ folder.)

4. Run:
   php artisan optimize:clear
   php artisan route:list
   npm run build
   php artisan serve

5. Open:
   http://127.0.0.1:8000/admin/curriculum

No migration and no seeder are required for this patch.
